Space Cadet Pinball

A port of 3D Pinball for Windows, running in your browser. It needs the original game data, which isn't included.

A test build. It carries the game data of all four tables, so it asks for no files. It holds Microsoft's files: keep it on your own devices and never publish it.

1. Add the game data. Choose PINBALL.DAT with its .WAV and .MID files and PINBALL.EXE, which holds the font of the messages, from 3D Pinball for Windows, or the folder of Full Tilt! Pinball (CADET.DAT). Add Full Tilt!'s DRAGON folder too, with DRAGON.DAT, to play Dragon's Keep, and its PIRATE folder, with PIRATES.DAT, to play Skulduggery; the game's title then lets you pick the table.

Where do I find these files?

3D Pinball for Windows came with Windows NT 4.0, Windows 2000, Windows Me and Windows XP, and before them with Microsoft Plus! for Windows 95. On an installed 32-bit Windows XP it lives in C:\Program Files\Windows NT\Pinball; choose that folder. On the Windows XP CD the files are compressed (PINBALL.DA_, SOUND1.WA_ and so on): unpack them with expand on Windows or cabextract elsewhere. Full Tilt! Pinball, which has the same table, came on its own CD.

Use a copy you own. This page doesn't download the game from anywhere.

The files stay in this browser (IndexedDB). They are never uploaded anywhere.
